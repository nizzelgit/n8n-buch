4 Grundlagen

Dein erster Workflow — Schritt für Schritt

Jetzt bauen wir gemeinsam etwas Echtes: Ein Workflow, der das aktuelle Wetter abruft, es lesbar aufbereitet und dir das Ergebnis zeigt. Jeder Klick ist einzeln beschrieben — bau einfach mit.

⏱ ca. 25 Minuten 🎯 Niveau: Einstieg 🧩 Voraussetzung: Kapitel 3

📋 Was du brauchst

  • n8n läuft und du bist im Editor (Kapitel 2).
  • Kein Konto, kein API-Schlüssel — wir nutzen eine offene, kostenlose Wetter-API (Open-Meteo).
  • Optional am Ende: ein Telegram-Bot, falls du das Ergebnis aufs Handy schicken willst (zeige ich als Kür).

Das Ziel

Am Ende dieses Kapitels hast du diesen Workflow gebaut und erfolgreich ausgeführt:

Schritt 1 — Neuen Workflow anlegen & benennen

  1. Neuen Workflow öffnen

    Klicke in der Übersicht oben rechts auf „+ Neuer Workflow“ (engl. Create Workflow). Du landest auf einem leeren Canvas mit dem großen + in der Mitte.

  2. Sofort benennen

    Klicke oben links auf „Mein Workflow“ und tippe Wetter-Report. Mit Strg/⌘ + S speichern.

Schritt 2 — Den Trigger hinzufügen

Jeder Workflow braucht einen Startpunkt. Zum Bauen nehmen wir den einfachsten: den manuellen Test-Trigger.

  1. Auf das große + klicken

    Klicke auf das + in der Canvas-Mitte. Es öffnet sich das Auswahl-Panel mit der Frage „Wie soll der Workflow starten?“.

  2. „Manuell“ wählen

    Wähle „Trigger manually“ (Manuell auslösen). Dieser Trigger feuert, wenn du auf den Test-Knopf drückst — ideal zum Entwickeln.

Nach der Auswahl liegt ein Trigger-Node (abgerundete linke Seite) auf dem Canvas. Der Canvas ist nicht mehr leer.

Schritt 3 — Den HTTP-Request-Node anhängen

Jetzt holen wir echte Daten. Wir hängen einen Node an, der eine Wetter-API aufruft.

  1. Verbindung ins Leere ziehen

    Fahre mit der Maus an den Ausgangspunkt (kleiner Kreis rechts) des Trigger-Nodes. Klicke und ziehe eine Linie nach rechts ins Leere, dann loslassen. Das Auswahl-Panel öffnet sich automatisch.

  2. HTTP Request suchen

    Tippe HTTP und wähle „HTTP Request“. Der Node erscheint und ist bereits mit dem Trigger verbunden.

  3. Node öffnen

    Doppelklicke den neuen Node, um die Detailansicht (NDV) zu öffnen.

  4. URL eintragen

    Lass die Methode auf GET. Trage bei URL die folgende Adresse ein (Wetter für Berlin, Open-Meteo, ohne Anmeldung):

  URL für das Feld „URL“
https://api.open-meteo.com/v1/forecast?latitude=52.52&longitude=13.41&current=temperature_2m,wind_speed_10m

  1. Diesen Schritt ausführen

    Klicke oben rechts im NDV auf ▶ Schritt ausführen. n8n ruft die URL auf. Rechts erscheint das Ergebnis als JSON. Du solltest unter current Werte wie temperature_2m sehen.

⚡ Erster Erfolg, erstes Muster Du hast gerade das Grundmuster aus Kapitel 0.1 in Aktion erlebt: einen Node bauen, ausführen, das Ergebnis anschauen. Genau so geht es jetzt mit jedem weiteren Node weiter.

Schritt 4 — Die Daten in einen Satz verwandeln

Rohes JSON ist nichts, was man verschicken will. Mit dem Edit-Fields-Node (heißt im Panel „Edit Fields (Set)“) bauen wir daraus einen lesbaren Satz. Dabei lernst du zum ersten Mal eine Expression kennen.

  1. Node anhängen

    Schließe das NDV (Klick aufs × oben rechts oder Esc). Ziehe vom Ausgang des HTTP-Nodes eine Linie ins Leere und wähle „Edit Fields (Set)“.

  2. Ein neues Feld anlegen

    Öffne den Node. Klicke auf „Add Field“ / „Feld hinzufügen“. Gib dem Feld den Namen nachricht.

  3. Auf „Expression“ umschalten

    Über dem Wert-Feld klickst du auf den Reiter Expression. Das Feld wird leicht bläulich — jetzt akzeptiert es Platzhalter in doppelten geschweiften Klammern.

  4. Die Expression eintippen

    Trage exakt das hier ein. Die {{ … }} holen den Temperaturwert aus dem vorherigen Node:

  Wert des Feldes „nachricht“ (Modus: Expression)
🌤️ In Berlin sind es gerade {{ $json.current.temperature_2m }} °C bei {{ $json.current.wind_speed_10m }} km/h Wind.
Was bedeutet $json? $json ist immer „die Daten des Items, das gerade hereinkommt“ — also die Ausgabe des vorherigen Nodes. Mit dem Punkt hangelst du dich durch die Struktur: $json.current.temperature_2m heißt „nimm current, darin temperature_2m“. Genau das vertiefen wir im nächsten Kapitel.

Schritt 5 — Den ganzen Workflow ausführen

  1. NDV schließen

    Drücke Esc, du siehst wieder den ganzen Canvas mit drei Nodes.

  2. Speichern

    Strg/⌘ + S.

  3. Test ausführen

    Klicke unten/oben auf den großen Knopf „Test workflow“ (bzw. Strg/⌘ + Enter). n8n läuft von links nach rechts durch. Jeder Node bekommt ein grünes ✓ und die Verbindungslinien färben sich kurz ein — die Daten „fließen“ sichtbar durch.

Geschafft! Du hast einen vollständigen Workflow gebaut, der echte Daten aus dem Internet holt, sie transformiert und ein sauberes Ergebnis erzeugt. Das ist das Skelett von 80 % aller Automatisierungen.

Kür — das Ergebnis aufs Handy (optional)

Wenn du magst, hängen wir einen letzten Node an, der den Satz per Telegram verschickt. Das braucht einen kostenlosen Telegram-Bot. Wenn dir das jetzt zu viel ist: überspring es — wir bauen so etwas in Kapitel 13 in Ruhe.

  1. Bot anlegen

    Schreibe in Telegram dem @BotFather, sende /newbot, folge den Fragen. Am Ende bekommst du ein Token (eine lange Zeichenkette). Schreibe deinem neuen Bot einmal „Hallo“, damit er dir antworten darf.

  2. Telegram-Node anhängen

    Ziehe vom Edit-Fields-Node eine Linie und wähle „Telegram“ → Aktion „Send a text message“.

  3. Credential anlegen

    Bei „Credential to connect with“ → „Create new“. Füge dein Bot-Token ein und speichere. (Mehr zu Credentials in Kapitel 12.)

  4. Empfänger & Text

    Bei Chat ID trägst du deine Telegram-ID ein (vom Bot @userinfobot bekommst du sie). Bei Text schaltest du auf Expression und nutzt {{ $json.nachricht }}.

  5. Ausführen

    Test starten — kurz darauf ploppt die Wetter-Nachricht in deinem Telegram auf. 🎉

Was du in diesem Kapitel gelernt hast

  • Einen Workflow anlegen, benennen und speichern.
  • Einen Trigger setzen und Nodes durch Ziehen verbinden.
  • Mit dem HTTP-Request-Node echte Daten aus einer API holen.
  • Mit Edit Fields Daten umformen und die erste Expression ({{ $json… }}) schreiben.
  • Einzelne Schritte und den ganzen Workflow ausführen und das Ergebnis prüfen.

Diese Expression hat sich wie Magie angefühlt? Ist sie nicht — sie ist das Herz von n8n. Das nächste Kapitel macht aus dem Bauchgefühl echtes Verständnis: Items, JSON und der Datenfluss.
