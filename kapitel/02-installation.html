Installation & Setup

Drei Wege führen zu n8n. Wähle einen — du kannst später jederzeit wechseln, deine Workflows lassen sich exportieren und importieren.

⏱ ca. 16 Minuten 🎯 Niveau: Einstieg 🧩 Du brauchst: Browser, optional Node.js oder Docker

Welcher Weg ist der richtige für dich?

WegAufwandFür wen?

Weg ① — n8n Cloud (empfohlen)

  1. Registrierungsseite öffnen

    Gehe im Browser auf n8n.io und klicke auf „Get started“ / „Start free“. Du landest auf einer Anmeldemaske.

  2. Konto anlegen

    Gib E-Mail und ein Passwort ein (oder melde dich mit Google/GitHub an). Bestätige ggf. deine E-Mail-Adresse.

  3. Workspace-Name & Region wählen

    n8n richtet dir eine eigene Instanz unter einer Adresse wie dein-name.app.n8n.cloud ein. Das dauert nur Sekunden.

  4. Du landest im leeren Editor

    Glückwunsch — genau diese Oberfläche begleitet dich durch das ganze Buch:

Weg ② — Lokal mit npx

Wenn auf deinem Rechner Node.js (Version 18 oder neuer) installiert ist, startest du n8n mit einem einzigen Befehl. Öffne ein Terminal und tippe:

  Terminal
# startet n8n und lädt es beim ersten Mal automatisch herunter
npx n8n

Beim ersten Start lädt n8n sich herunter (das kann ein, zwei Minuten dauern). Danach erscheint im Terminal eine Zeile wie diese:

  Terminal-Ausgabe
Editor is now accessible via:
http://localhost:5678

Press "o" to open in Browser.
1 Browser öffnen → 2 localhost:5678 eingeben → 3 Owner-Konto anlegen → 4 fertig

Beim ersten Aufruf legst du ein Owner-Konto an (Name, E-Mail, Passwort). Das ist nur lokal und schützt deinen Editor — keine Daten verlassen deinen Rechner.

Achtung: Daten weg beim Schließen? Mit npx n8n liegen deine Workflows in einem versteckten Ordner ~/.n8n. Solange du den nicht löschst, bleiben sie erhalten — auch nach einem Neustart. Schließt du nur das Terminal, ist n8n bloß gestoppt, nicht gelöscht. Mit npx n8n startest du es wieder.

Weg ③ — Docker (für dauerhaftes Self-Hosting)

Docker ist die sauberste Variante für den Dauerbetrieb. Du brauchst eine installierte Docker-Umgebung. Der folgende Befehl startet n8n und legt die Daten in einem benannten Volume ab, damit nichts verloren geht:

  Terminal
# 1) ein Volume für persistente Daten anlegen
docker volume create n8n_data

# 2) n8n starten, Port 5678 nach außen geben
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

Auch hier öffnest du danach http://localhost:5678. Für einen echten Server kommen später noch eine feste Domain, HTTPS und Umgebungsvariablen dazu — das vertiefen wir in Kapitel 24 (Deployment).

Cloud vs. Self-Hosting — der eine echte Unterschied In der Cloud funktionieren Webhooks sofort (du bekommst eine öffentlich erreichbare Adresse). Lokal ist dein localhost von außen nicht erreichbar — für Webhook-Tests brauchst du dann ein kleines Hilfsmittel (Tunnel), das wir in Kapitel 7 zeigen. Für die ersten Kapitel spielt das keine Rolle.

Der erste Login — was du siehst

Egal welcher Weg: Nach dem allerersten Start fragt n8n ein paar Dinge ab (Owner-Konto, optional eine kurze Umfrage „Wofür nutzt du n8n?“). Danach bist du im Editor. Vielleicht begrüßt dich ein leerer Canvas mit dem großen + wie in Abb. 2.1 — manchmal auch eine kurze Tour. Beides kannst du gefahrlos wegklicken.

✅ Checkliste: Bereit für Kapitel 3?

  • Du siehst den Editor mit dem leeren Canvas.
  • Oben rechts erkennst du den Speichern-Button und den Aktiv/Inaktiv-Schalter.
