Spickzettel: die wichtigsten Nodes

n8n hat viele Nodes. Du brauchst am Anfang nicht alle. Dieser Spickzettel ordnet die wichtigsten Bausteine danach, welches Problem sie lösen: starten, holen, verändern, verzweigen, warten, schreiben und antworten.

⏱ ca. 10 Minuten 🎯 Niveau: Nachschlagen 🧩 Voraussetzung: Kapitel 5
80/20 für Nodes Die meisten Einsteiger-Workflows entstehen aus zehn Bausteinen: Manual Trigger, Schedule Trigger, Webhook, HTTP Request, Edit Fields, IF, Switch, Merge, Code und Respond to Webhook.

Auswahlregel

  1. Start klären

    Kommt das Ereignis per Zeitplan, Webhook, Formular, manuell oder aus einem Dienst?

  2. Datenquelle bestimmen

    Gibt es einen passenden App-Node? Wenn nicht, prüfe HTTP Request.

  3. Transformation klein halten

    Nutze Edit Fields, Filter, Sort und Limit, bevor du Code einsetzt.

  4. Verzweigung sichtbar machen

    Nimm IF für zwei Wege, Switch für mehrere Wege.

  5. Schreibende Nodes absichern

    Prüfe Dubletten, Testdaten und Credentials, bevor Daten extern verändert werden.

Antworten 1) IF für zwei Wege, Switch für mehrere Fälle. · 2) Ein App-Node ist oft lesbarer und führt dich besser durch Authentifizierung und Felder. · 3) Ziel, Testdaten, Dubletten und Credentials. · 4) Weil unklar ist, welche Items fachlich zusammengehören. · 5) Wenn GUI-Nodes die nötige Transformation nicht sauber ausdrücken.
